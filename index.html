Building HTML Lists

Embedded Style Sheet
A collection of CSS style rules placed inside a <style> tag within the <head> section of an HTML document.
External Style Sheet
A separate .css file containing style rules that is linked to an HTML document using the <link> tag.
Inline Style
CSS applied directly to a single HTML element using the style attribute.
